# AI-Powered Smart HealthGuard

Educational AI full-stack platform for medicine/product information analysis.

## Planned features
- Medicine/product information analyzer
- Package image upload and OCR
- Suspicious-product risk scoring using ML + rules
- AI assistant
- User analysis history
- Admin/data management
- MongoDB product database
- Docker and cloud deployment
- Android/Google Play Store release

> Educational project only. It is not a medical diagnosis or prescription system.
